# waiting-room-jdbc

`waiting-room` 의 저장을 DB 에 둔다 — 아직 구현 전이다(자리만 잡혀 있다).

| 항목 | 내용 |
|---|---|
| 의존성 한 줄 | `implementation(project(":modules:waiting-room-jdbc"))` |
| 함께 오는 모듈 | `waiting-room`, `platform` |
| 컴파일 전용 | 없음 |
| 설정 접두사 | 없음 |
| 기본 동작 | 꺼짐 — 구현 전이라 아무것도 등록하지 않는다. |
| 부팅에 필요한 것 | 없음 |
| 교체 지점 | 없음 |
| 마이그레이션 | 없음 |
| 프론트 짝 | 없음 |
| 테스트 | `modules/waiting-room-jdbc/src/test` |
