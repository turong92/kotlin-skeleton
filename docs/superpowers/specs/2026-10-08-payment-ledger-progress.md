## 주인 결정 (스펙과 다르면 이쪽이 이긴다)
- 가-1 `payment` 안 + 새 모듈 `payment-jdbc` · 가-3 스펙 추천 이름 · 가-4 결제창 + API 개별 연동 키

- 나-5 **카드사 + 끝 4자리 저장**(스펙 추천과 다름) → 탈퇴 익명화 때 두 칸 지움, 전체 표 스캔 · 업그레이드 시험 포함. 번호 · 유효기간 · 소유자명은 저장 금지

- 공개 저장소: 회사 이름 · 내부 경로 · 회사 코드 금지

## 계약 세부 (리드가 정함 — 백엔드 · 프론트 공통, B7 계약 문서에 적을 것)
- 승인 요청 본문 `{ providerPaymentId, amount: number }`(최소 단위 정수)
- 본인 환불 요청 `reasonCode`: `CUSTOMER_REQUEST | DUPLICATE | NOT_DELIVERED` 만(그 밖은 400). 운영자 환불 origin 은 `OPERATOR`
- `DECLINED` 의 `data.category`: `LIMIT_OR_BALANCE | CARD_DECLINED | TEMPORARY | OTHER` · `REFUND_DECLINED` 의 `data.category`: `ALREADY_REFUNDED | AMOUNT_EXCEEDED | PARTIAL_NOT_ALLOWED | PERIOD_EXPIRED | TEMPORARY | OTHER`
