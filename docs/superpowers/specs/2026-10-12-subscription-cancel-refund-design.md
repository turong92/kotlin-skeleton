# 구독 해지·환불 (구독 3차) — 짧은 설계

날짜 2026-10-12. 근거 조사: `annual-refund-research.md`, `toss-international-research.md`, `overseas-subscription-providers.md`.

## 형 결정 (원문)
- "따로 묶음, 먼저" — 중도 해지 환불 · 7일 청약철회를 해지·환불 묶음으로 먼저. 가격 인상 고지는 상품·가격 스펙에서.
- "이거 글로벌은 다 워킹하는게 다를텐데 쪼개놓을 수 있니?" → 나라별로 갈아 끼우는 해지·환불 정책 부품.
- 나라는 "결제 할 때 국가를 받던가" → 구독 결제 화면에서 받음(토스 응답에는 나라가 없다 — 조사).
- "토스 기준으로 하긴 할건데" — 해외 결제사(MoR)는 별도 묶음.

## 만드는 것
1. **해지·환불 정책 계약** (`payment` 모듈) — 구독 하나(나라·결제 내역·기간)를 받아 답한다: 중도 해지를 여나 / 지금 해지하면 얼마 돌려주나(내역 포함) / 철회 기간.
   - 기본 구현 ① **기간 끝 해지만**(스켈레톤 기본, 옵션 없음): 중도 해지 닫힘, 환불 0.
   - 구현 ② **한국 소비자 정책**: 중도 해지 열림. 환불 = 낸 돈 − 쓴 몫 − 위약금.
     - 쓴 몫: 월 주기는 일할(남은 시간 비율). 월보다 긴 주기(연간 등)는 쓴 개월 × 같은 등급의 월 가격(없으면 일할) — 할인은 쓴 몫에 안 쳐 준다.
     - 위약금 = 남은 금액 × 비율(설정, 기본 0%, 견본 앱 10%).
     - 7일 철회: 이번 기간 첫 결제 후 7일 안이고 "안 썼으면" 전액. "썼는가"는 앱 계약(기본: 7일 안이면 안 쓴 것으로).
     - 2차의 플랜 올리기 차액도 "낸 돈"에 포함(같은 기간에 낸 주문 전부).
   - 나라 → 정책 고르기는 설정 지도(`KR: korea`, 그 밖은 기본).
2. **나라 칸** — 구독을 만들 때 구매자 나라(ISO-3166 두 글자)를 받아 구독 줄에 박는다(새 열, V 파일 두 방언). 화면은 언어·지역으로 미리 채우고 바꿀 수 있게. 비면 설정의 기본 나라.
3. **중도 해지 API** — 미리보기(환불 예정 금액·내역) + 실행. 실행 = 구독 즉시 `ENDED`(`USER_CANCELED_NOW`) + 이번 기간 주문들에 부분 환불을 기존 환불 장부로 요청(결제사 호출은 기존 경로) + 빌링키 삭제. 이미 해지 예약 중이어도 가능.
4. **화면** — 「내 구독」에 해지 단추 둘을 같은 무게로: 「기간 끝에 해지」 / 「지금 해지하고 환불」(정책이 닫았으면 안 보임). 지금 해지는 확인 대화상자에 환불 예정 금액과 계산 내역.

## 안 만드는 것
가격 인상 고지(상품·가격 스펙), 해외 결제사(MoR 묶음), 운영자 화면 개편, 앱스토어 결제, 해외 카드 환율 안내.

## 위험·테스트(사고 나는 것만)
- 환불 합계가 이번 기간에 낸 돈을 넘지 않는다 / 두 번 눌러도 환불 한 번(멱등) / 갱신 과금 중에는 중도 해지 409 / 7일 철회 경계(7일 직전·직후) / 위약금 내림 / 연간 쓴 몫 계산 표.

## 크기
조각 2(백·프), developer 1명(2차 인계 메모 + 이 문서), 리뷰 1 + 확인 1, 끝 검사 1(+1). 1~2시간.
